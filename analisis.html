SSI1144 Algoritma dan Pengantar Pemrograman

Latar Belakang dan Rumusan Masalah

Koperasi membutuhkan cara yang sistematis untuk memantau persediaan barang. Pencatatan manual rawan salah hitung, terutama saat stok awal, barang masuk, dan barang terjual harus dihitung satu per satu. Akibatnya, koperasi bisa terlambat mengetahui barang yang hampir habis, sehingga pemesanan kembali terlambat dan penjualan terganggu.

Program evaluasi persediaan ini menghitung stok akhir, menentukan status tiap barang (Habis, Menipis, atau Aman), dan menghitung jumlah serta biaya pemesanan kembali.

Rumusan masalah:

  1. Bagaimana menghitung stok akhir dari stok awal, barang masuk, dan barang terjual?
  2. Bagaimana menentukan status barang berdasarkan stok akhir dan stok minimum?
  3. Bagaimana menghitung jumlah dan biaya pemesanan kembali untuk barang yang habis atau menipis?
  4. Bagaimana mencegah data yang tidak masuk akal, seperti nilai negatif atau penjualan melebihi stok?
  5. Bagaimana merekap hasil evaluasi banyak barang tanpa menggunakan array?

Tujuan dan Pengguna

Tujuan: membuat program C++ berbasis console yang mengevaluasi persediaan beberapa barang dan menampilkan rincian serta rekapitulasinya.

Pengguna: petugas koperasi yang mencatat stok barang, dan pengurus koperasi yang membaca rekapitulasi persediaan untuk menentukan pemesanan kembali.

Ketentuan dan Batasan

  • Stok akhir = stok awal + barang masuk - barang terjual.
  • Penjualan tidak boleh melebihi stok yang tersedia (stok awal + barang masuk).
  • Stok akhir 0 berstatus Habis; di bawah stok minimum berstatus Menipis; sama dengan atau di atas stok minimum berstatus Aman.
  • Barang Habis atau Menipis dipesan sampai stok mencapai dua kali stok minimum.
  • Program berjalan di console dengan bahasa C++, memakai variabel, operator, percabangan, dan perulangan.
  • Program tidak menggunakan array, class, database, GUI, atau library eksternal.
  • Program menolak input negatif dan input yang bukan angka, lalu meminta input ulang.
  • Program menyediakan pilihan untuk mengulang atau mengakhiri proses.
