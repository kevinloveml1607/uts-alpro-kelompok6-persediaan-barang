Kesalahan dan Perbaikan

Kevin Sebastian Liem

  • Flowchart Modul A: arah panah ke Selesai terbalik, serta label Ya/Tidak dan kepala panah belum lengkap. Flowchart dikoreksi dan digambar ulang sampai sesuai dengan pseudocode.
  • File modul_a.cpp rusak karena proses menempel terganggu mode timpa (OVR) dan saran otomatis Copilot. Mode OVR dimatikan dan isi file diganti dengan versi lengkap.
  • Git menampilkan "nothing to commit" dan kompilasi gagal karena file belum disimpan. File disimpan dengan Ctrl + S lalu diproses ulang.
  • Halaman Modul A memiliki judul dan kartu ganda karena isi ditempel di tengah baris placeholder. Bagian ganda dirapikan dengan Find and Replace.
  • Nama file gambar tidak sama dengan nama pada HTML sehingga gambar tidak tampil. File diganti namanya agar sesuai.

Rencana Pengembangan UAS

Pada tahap UAS, program dapat dikembangkan dengan menggunakan array dan function agar data barang dapat disimpan dan diproses ulang tanpa harus mengulang input. Program juga dapat ditambah fitur penyimpanan data ke file, pencarian barang berdasarkan kode, dan urutan barang berdasarkan penjualan. Kedua modul dapat digabung dalam satu program yang lebih terstruktur dengan pembagian function yang jelas.
