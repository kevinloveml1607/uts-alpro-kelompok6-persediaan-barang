1. Claude (Anthropic)

Nama alatClaude (Anthropic)
TujuanMenuntun pembuatan repository dan struktur folder GitHub Pages, menuntun pengerjaan Modul A di VS Code, serta membantu memperbaiki flowchart, algoritma deskriptif, pseudocode, dan kode C++ Modul A.
Prompt utama

Prompt awal: "baca seluruh dokumen ini, saya dan teman saya lucy ingin mengerjakan projek ini studi kasus 6, saya modul a dan lucy modul b, bantu dan tuntun saya mulai bikin repository dan mulai kerja di vs code, kami menggunakan bahasa c++, dan bantu aku untuk membuat repo nya sesuai struktur dari uts yg di inginkan"

Prompt lanjutan: "bikin flowchart nya yang betul terkadang masih berantakan" dan "perbaikin semua kode nya dl".

Bagian hasil yang digunakanDraf analisis masalah dan tabel variabel, algoritma deskriptif, pseudocode, kode modul_a.cpp, gambar flowchart Modul A hasil perbaikan, kerangka isi halaman modul-a.html, dan daftar skenario pengujian.
Perubahan yang dilakukan mahasiswa
  • Menggambar flowchart awal sendiri di draw.io, lalu memperbaikinya setelah dikoreksi (arah panah ke Selesai, label Ya/Tidak, kepala panah, dan teks).
  • Memasukkan seluruh konten ke halaman kerangka dari Copilot, serta memperbaiki bagian yang tertempel ganda.
  • Memperbaiki file modul_a.cpp yang rusak karena salah tempel dan mode timpa (OVR) di VS Code.
  • Menyesuaikan nama file gambar agar sama dengan yang dipakai di HTML.
Hasil verifikasi mahasiswa
  • Kode dikompilasi dengan g++ dan dijalankan di VS Code tanpa error.
  • Program diuji dengan data nyata, misalnya stok awal 10, barang masuk 5, terjual 12, stok minimum 5, harga beli 2000, menghasilkan stok akhir 3, status Menipis, pesan 7 unit, biaya Rp14000, sesuai hitungan manual.
  • Input negatif, huruf, dan penjualan melebihi stok ditolak dan program tetap berjalan.
  • Sepuluh skenario pada tabel pengujian pertama kali dijalankan melalui Claude dengan kode yang sama, kemudian saya jalankan ulang sebagian skenario di komputer sendiri untuk memastikan hasilnya sama.
  • Tampilan halaman dicek lewat Live Server dan GitHub Pages.
